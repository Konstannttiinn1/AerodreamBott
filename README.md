# Aerodream Telegram Bot

Полнофункциональный Telegram-бот для бизнеса (пример — aerodream.spb.ru), построенный на **aiogram 3.x**. Бот предназначен для автоматизации общения с клиентами, приёма заявок, рассылок и маркетинговых сценариев (follow-up).

Проект спроектирован как **production-ready решение** с админ-панелью, базой данных, автоматизацией и возможностью дальнейших интеграций (CRM, n8n, webhooks).

---

## 🚀 Возможности бота

### 👤 Пользовательская часть

Пользователь взаимодействует с ботом через удобное меню:

* `/start` — приветствие и главное меню
* **О сервисе** — описание компании (контент из `content.yaml`)
* **FAQ** — интерактивный список вопросов/ответов
* **Цены** — тарифы и кнопка запроса скидки
* **Как добраться** — адрес и ссылка на карту
* **Подготовка / Правила** — инструкции перед посещением
* **Контакты** — связь с администратором + управление подпиской

Дополнительно:

* Учёт активности пользователя (last_seen)
* Подписка / отписка от уведомлений
* Защита от спама (cooldown, проверки подписки)

---

### 🎯 Автоматизация (Follow-up после просмотра цен)

Бот поддерживает автоматический сценарий:

1. Пользователь открывает раздел **«Цены»**
2. Если автоматизация включена:

   * через **T1 часов** приходит напоминание
   * через **T2 часов** — предложение со скидкой
3. Flow автоматически останавливается, если:

   * пользователь отписался
   * пользователь перешёл в «Контакты»
   * пользователь запросил скидку

Особенности:

* Cooldown 24 часа (не спамит при повторных заходах)
* Все тексты и тайминги настраиваются из админки
* Сценарии хранятся в БД (`user_flows`)

---

### 🧑‍💼 Админ-панель (`/admin`)

Доступна только пользователям из `ADMIN_IDS`.

Функционал:

#### 📊 Статистика

* Всего пользователей
* Новые за 7 дней
* Активные за 30 дней
* Заблокированные
* Подписанные
* Сколько раз открывали «Цены»
* Количество запросов скидки

#### 🎁 Запросы на скидку

* Просмотр новых заявок
* Отметка «обработано» / «отклонено»
* Комментарий к заявке
* Быстрый переход к чату с пользователем

#### 📣 Рассылки

* Мастер рассылки с preview
* Аудитории:

  * тест (только админам)
  * всем подписанным
  * активным / неактивным за N дней
* Rate limit отправки
* Учёт доставленных / недоставленных сообщений

#### 🤖 Автоматизация

* Включение / выключение follow-up
* Настройка T1 и T2
* Изменение текста напоминания и предложения

#### 🗑 Dev-инструменты

* **Удаление пользователя по user_id** (безопасно)
* Полная очистка его данных:
  `users`, `events`, `user_flows`, `discount_requests`

---

## 🗄 База данных (SQLite)

Используется `aiosqlite`. Таблицы:

* `users` — пользователи бота
* `events` — события (start, prices_open и т.д.)
* `discount_requests` — заявки на скидку
* `broadcasts` — история рассылок
* `settings` — настройки автоматизации
* `user_flows` — активные и завершённые сценарии

Путь к БД настраивается через `DATABASE_PATH`.
